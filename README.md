# Вместе · 4.2.0

Уютное PWA для пары или компании: 158 занятий, свои идеи, общие планы, настольные и экранные игры. Статические HTML/CSS/JS, локальные данные и WebRTC без собственной серверной базы.

## Запуск

```sh
npm ci
npm start
```

Откройте http://127.0.0.1:4173. Для публикации используются GitHub Pages из main; относительные пути работают в подкаталоге. После изменения ресурсов выполните `node scripts/finish-assets.mjs`. HTTPS необходим для PWA и Web Crypto.

## Комнаты и устройства

Создайте парную комнату на двух участников либо дружескую на десять. Отправьте приглашение. Новый участник и принимающий сверяют одинаковые значки и подтверждают соединение с обеих сторон. До завершения проверки данные комнаты не передаются. Уже знакомые устройства подключаются автоматически.

Принимающий может выделить новую роль, подключить ещё одно устройство существующего участника или отдельный экран. Экран не занимает место игрока и получает публичную сцену игры, без личных заданий и базы идей. На компьютере можно играть обычным участником либо показывать общий экран. Менять игры можно без повторного подключения.

Комнаты сохраняются в профиле, между ними можно переключаться. Шесть эмодзи комнаты — удобная визуальная подпись, а не код авторизации; под приглашением доступен настоящий случайный идентификатор. Идентичность устройства подтверждается подписью P-256, привязанной к конкретному DTLS-соединению. Знание ссылки само по себе не даёт доступ к данным.

Если устройство потеряло данные, откройте приглашение рядом с сохранившимся участником: он назначает прежнюю роль и передаёт реплицированные записи. Если потеряны все доверенные устройства, автоматическое восстановление доверия невозможно. JSON-экспорт и импорт остаются доступны. Для прежней ситуации «Свят и Свят» есть «Исправить имена» в профиле: имена меняются без замены ролей и лайков.

## Идеи и планы

Полный каталог с поиском и фильтрами сохранён. Выше — сезонные подборки с учётом времени суток. Плавающая кнопка открывает Discover: сначала свежие понравившиеся, затем перемешанные остальные, без повторений до конца колоды. В конструкторе можно листать карточки в план, пользоваться лентой рекомендаций и генерировать вечер по месту, настроению и времени.

Сердечко ставит лайк, удержание — суперлайк. Старое избранное отображается как суперлайки. Взаимные лайки дают сердечко, два суперлайка — сияние. Старые пропуски не скрывают занятия.

Для своей идеи выбирается готовая иллюстрация из галереи либо эмодзи. Ранее добавленные фотографии сохраняются. Возвращены прежние значки профиля и добавлены люди, фантазийные персонажи и другие образы.

## Игры

«Музей невозможного» — многораундовая игра с тайными заданиями художника, рисованием с телефона, выдуманными подписями, голосованием и раскрытием авторов. За правильные догадки и убедительные выдумки начисляются очки; художники меняются. В конце сохраняется выставка, которую можно открыть снова или вывести на экран. Для двоих используются дополнительные подписи от игры.

На полке также вопросы, правда/действие, предсказания ответов, данетки, выборы, пантомима, ассоциации, совместные стихи, рисование с угадыванием, совместный маяк и короткие гонки с управлением телефонами. Вопросы и правда используют общий пул. Собственные свежие карточки идут первыми, с несколькими давно сыгранными; история использования объединяется между устройствами.

«Общая тишина» — медитация с четырьмя настройками настроения. «Сад звука» — отдельное совместное музицирование: восемь слоёв, касания и влияние друг на друга. Каждый телефон играет свою партию. Движок процедурно создаёт природные шумовые текстуры, плавные переходы и реверберацию; это не AI и не библиотека записанных природных лупов. На каждом устройстве звук запускается отдельным нажатием. Точная синхронизация аудио по сэмплам не обещается.

## Обновление и сохранность

В профиле нажмите «Проверить обновление», затем «Обновить приложение». Обновите оба телефона и общий экран до 3.1.0: протокол подключения изменился. При переходе с 1.0 с интернетом один раз перезагрузите страницу, чтобы появилась независимая плашка обновления. Очищать данные сайта и переустанавливать приложение не нужно.

Обновление сохраняет IndexedDB, личность, идеи, реакции и планы; перед перезапуском сохраняется текущий план. Закончите ввод в открытой форме. Старые резервные копии поддерживаются. Ключи доверия не включаются в обычный экспорт комнаты.

Данные доступны офлайн после первого открытия. Обмен между устройствами требует одновременного подключения. PeerJS Cloud используется для сигнализации; серверного бэкапа нет. Прямое соединение зависит от сети/NAT, отдельный TURN не настроен. Живой раунд при уходе ведущего может потребовать перезапуска.

## Проверки

`npm test` — хранилище, синхронизация, подписи, согласие и миграция ролей. При работающем сервере: `npm run test:browser`, `node tests/update.mjs`, `node tests/recovery.mjs`, `node tests/v3.mjs`, `npm run test:rooms`, `npm run test:party`, `npm run test:museum`. `npm run test:pwa` запускает собственный сервер для перехода с настоящей 1.0; `PWA_WAITING_2=1` добавляет ожидающее обновление 2.0.

Проверки Chromium используют настоящий WebRTC: десять игроков, дополнительный экран, восстановление роли и полные партии «Музея» на двух и трёх участников. Физические iPhone/Android, системная установка и звучание на реальных динамиках отдельно не проверялись.

## 3.1 · Секретная частота

Вторая многораундовая игра для 2–10 участников и отдельного общего экрана. Подсказчик видит тайную точку на шкале между двумя понятиями, остальные получают только его образ-подсказку. Каждый фиксирует догадку со своего телефона; позиции скрыты до общего раскрытия. Командная точка — среднее, созвучие — близость к тайной частоте. За партию подсказчики меняются, в финале видны все пройденные волны и результат относительно прежних партий с тем же числом участников. Досрочно завершённая партия не создаёт рекорд.

24 шкалы ротируются с учётом общей истории. Это игра об ощущениях и разговоре, без правильных личных вкусов и без ограничения времени. Ведущим может быть любой участник, общий экран остаётся подключённым при смене игры.

Проверка: `npm run test:frequency`; `FREQUENCY_TEN=1` проверяет большую компанию.

## Версия 4.0

Единые столы с приглашением, готовностью и историей; независимые игровые сессии, одиночные звуковые инструменты и свёрнутый плеер. Два XY-пульта в «Саду звука», удерживаемые созвездия с длительным следом в «Общей тишине». Новые восьмиэтапные сценарии, постоянные офлайн-миры и асинхронные письма с тихой лентой событий.

Комнаты выбираются нажатием на название в шапке. Файлы, установка, обновление, история и режим монитора находятся в компактных настройках с иконками. Фильтры доступны и в каталоге, и непосредственно при листании. Сердечки работают в плане. Добавлены 14 иллюстраций и тематические группы идей.

План и состояние работ: [ROADMAP.md](ROADMAP.md). Устройство игр и роль монитора: [GAME_DESIGN.md](GAME_DESIGN.md). Проверки новых функций: `npm run test:party`, `npm run test:worlds`, `npm run test:sound`, `npm run test:pwa`.

Для совместной игры оба устройства должны использовать актуальную версию. В установленной PWA проверьте обновление в настройках. Данные не удаляются при обновлении. Непрочитанное отмечается отдельно на каждом устройстве; сами письма, ответы и постоянные миры входят в общую историю и JSON-копию.
