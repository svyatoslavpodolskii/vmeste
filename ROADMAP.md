# Вместе — состояние доработки

Обновлено: 31 октября 2026. Основа взята из GitHub, commit `2de22fd` (3.1.0). Версия 4.0.0 опубликована в GitHub Pages и проверена по настоящему HTTPS-адресу. Этот файл хранится вместе с исходниками и предназначен для продолжения работы с другого компьютера.

## Уже реализовано и проверено

- [x] Общая история карточек: назад на любую пройденную карточку; сохранение всей колоды, новые авторские карточки вставляются без перемешивания остальных.
- [x] История свайпов идей с кнопкой назад, в том числе после добавления идеи в план.
- [x] Приглашение, участники, готовность и начало партии: секундомер не идёт в лобби.
- [x] Два одновременно созданных лобби одной игры выбирают один общий стол; проверено с настоящим PeerJS.
- [x] Восстановление ведущего после reload без создания новой партии; приглашённым повторно передаётся активная игра при подключении.
- [x] «Созвучия» и стихи: одна кнопка «Готово», отмена и редактирование до готовности всех, затем общее раскрытие.
- [x] «Правда или действие»: реальный выбор и очередь игроков.
- [x] «Две двери»: скрытые нажатия с телефонов, одновременное раскрытие, обсуждение без таймера.
- [x] Рисование: устный ответ и явная кнопка «Угадали»; на общем экране только правильный ответ после подтверждения.
- [x] «Секретная частота»: устная подсказка по умолчанию, текст как необязательный запасной способ.
- [x] Музей: задания из двух простых образов, оформление выставки, длинная партия.
- [x] «Сад звука»: два XY-пульта, четыре угла смешивания, разные формы и роли, заметное влияние на фильтры, гармоники и движение; два источника на слой с постепенным смешиванием.
- [x] «Общая тишина»: XY-настроение и удерживаемые созвездия с разной длительностью и силой послезвучия.
- [x] Свёрнутый плеер: открыть пульт, пауза, продолжить, полностью выключить.
- [x] Убраны повторяющиеся кнопки рядом с сезонными идеями; каталог листается горизонтально.
- [x] Лайк и суперлайк в подробностях — SVG-кнопки с явным выбранным состоянием.
- [x] Служебные циклы обмена данными скрыты за устойчивым состоянием «На связи».
- [x] Две новые многоэтапные игры: «Острова наизнанку» (экран по желанию) и «Комната с разломом» (ПК обязателен). Восемь этапов: асимметричные сигналы, память, равновесие, скрытый риск, общий корабль с разделённым управлением.
- [x] Маяк и светлячки используют многоэтапные сценарии вместо единственного простого действия.
- [x] PWA 1.0 → 4.0: автоматическая проверка сохранности личности, комнаты, идей, реакций, планов, заданий и черновика прошла.

## Последние уточнения — реализовано

- [x] Параллельные столы: одиночный звук и другая игра не должны вытеснять друг друга. При входе в одинаковую игру — общий стол.
- [x] Ненавязчивое приглашение, когда человек уже занят другой игрой; красная отметка и понятное возвращение.
- [x] Одиночный звуковой режим со всеми пультами; возможность присоединиться второму.
- [x] Долгосрочный след созвездий: после затухания остаётся мягкое влияние на алгоритм и гармонию.
- [x] Фильтры непосредственно в свайпах.
- [x] Меню комнат по нажатию на название: сохранённые комнаты, создать, войти, настройки.
- [x] Компактные настройки с иконками: файлы, экран, история/выставки, обновление и установка; убрать россыпь серых кнопок из профиля.
- [x] Настоящая кнопка лайка у занятия в плане.
- [x] Больше локальных иллюстраций и точных тематических групп идей вместо одинаковых изображений подряд.
- [x] Характерные визуализации игр на ПК и проверка мобильных размеров после последних изменений.
- [x] Асинхронные миры: совместный сад и карта открытий; действия каждого сохраняются отдельно и объединяются после офлайна.
- [x] Явная роль монитора в каждой игре: по желанию / удобнее с экраном / обязателен; экранные представления также для долгоживущих миров.
- [x] «Между строк»: асинхронные вопросы и текстовые ответы, история по вопросам, непрочитанное, спокойная единая лента событий без потока звуков и всплывающих сообщений.

## Как продолжить

`npm ci`, `npm start`, `npm test`. Проверки нового игрового каркаса: `node tests/revision4.mjs`; чистые проверки колод/согласования/восьми этапов: `node tests/games4.test.mjs`. Звук: `node tests/sound.mjs`. Миграция PWA: `node tests/pwa-update.mjs`.

Основные новые модули: `js/deck-session.js`, `js/game-protocol.js`, `js/expedition.js`, `js/sound-controls.js`, `css/instruments.css`. Изменения транспорта — `js/peer.js`, координация игр — `js/party.js`.

Честная граница проверки: Chromium с отдельными контекстами и настоящим PeerJS; физические телефоны и субъективное прослушивание человеком пока не проверены. Уровень Jackbox/Mario Party — ориентир для развития, а не заявление о достигнутом объёме или качестве.
